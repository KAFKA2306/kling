# テスト: コールバックプロトコル

このディレクトリでは FastAPI のテストクライアントとモックを用いて、コールバック受信ルートが仕様通りに動作するかを検証します。

## テストの焦点
- 署名検証エラーやバリデーションエラーが正しいステータスコードで返るか。
- `register_callback_handler` に登録した関数が非同期タスクとして呼び出されるか。
- 正常系で `CallbackAckResponse` が返却されるか。

## 実行
プロジェクトルートで `pytest api/callback_protocol/_tests` を実行してください。非同期処理の検証には `pytest-asyncio` を利用しています。
