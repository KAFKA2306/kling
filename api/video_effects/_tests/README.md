# テスト: 動画エフェクト API

`api/video_effects/_tests` は動画エフェクトクライアントのユニットテストを収録しています。HTTPX のモックと Pytest を組み合わせ、例外ハンドリングやリトライ挙動を網羅的に検証します。

## 主なファイル
- `test_video_effects.py`: タスク作成・取得・一覧・キャンセルの各メソッドが正しいリクエストを送信し、期待するレスポンス・例外を返すかを確認。
- `conftest.py`: モッククライアントやサンプルレスポンスを提供する共通フィクスチャ。

## 実行方法
プロジェクトルートから `pytest api/video_effects/_tests` を実行してください。リトライ検証には `pytest` のモック機能を用いているため、外部通信なしで高速に完了します。
