# 画像生成 API

`api/image_generation` は Kling AI の画像生成エンドポイントにアクセスするためのクライアント実装を含みます。テキストプロンプトと参照画像を組み合わせて静止画を生成し、タスク管理やポーリングも行えます。

## 主なファイル
- `image_generation.py`: `KlingImageGenerator` クラスを提供し、タスク作成・取得・一覧・完了待ちを実装。
- `_requests.py`: プロンプトや解像度、参照画像 URL などの入力を Pydantic モデルとして定義。
- `_responses.py`: 生成結果・タスク状態・ページング情報を型安全にパース。
- `_exceptions.py`: API 通信時のエラーを抽象化。
- `_tests/`: クライアントの振る舞いを Pytest で検証。

## 対応機能
- テキストのみ、または参考画像付きでの生成。
- アスペクト比・ fidelity・生成枚数の細かい調整。
- コールバック URL の設定と非同期完了待ち。

画像生成ワークフローを実装する際は、本モジュールのクライアントを `KlingClient` 経由で利用してください。
