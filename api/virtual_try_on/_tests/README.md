# テスト: バーチャル試着 API

`api/virtual_try_on/_tests` にはバーチャル試着クライアントのユニットテストがまとまっています。HTTPX のモックレスポンスを用いて、API 呼び出しの成功/失敗パターンやモデルのバリデーションを確認します。

## テスト構成
- `test_api.py`: `VirtualTryOnAPI` のタスク作成・取得・一覧が正しい HTTP メソッド・パスで呼ばれるかを検証。
- `test_models.py`: リクエスト/レスポンスモデルが期待通りにシリアライズ・デシリアライズできるかをチェック。
- `conftest.py`: モック HTTP クライアントや共通フィクスチャを定義。
- `pytest.ini`: このモジュール専用の Pytest 設定。
- `__init__.py`: パッケージ化のための空ファイル。

## 実行
ルートディレクトリから `pytest api/virtual_try_on/_tests` を実行すると、本ディレクトリ配下のテストが走ります。外部通信はすべてモック化されるため、ネットワーク接続は不要です。
