# テスト: リップシンク API

`api/lip_sync/_tests` ではリップシンククライアントの正常系と失敗系を Pytest で検証します。

## テストファイル
- `test_lip_sync.py`: タスク作成・取得・一覧 API が想定どおりに呼ばれるか、例外が適切に投げられるかを確認。
- `conftest.py`: 共通のモック HTTP クライアントやフィクスチャを提供。
- `__init__.py`: パッケージとしてテストを import しやすくするための空ファイル。

## 実行方法
ルートから `pytest api/lip_sync/_tests` を実行してください。`tenacity` のリトライ挙動はモック化されているため、テストは高速に完了します。
