# リップシンク API

`api/lip_sync` は音声に合わせて口の動きを生成する Kling AI リップシンクサービス向けのクライアント実装です。レート制限対策や詳細なエラーハンドリングを備え、安定した音声同期動画の生成を支援します。

## 主なファイル
- `lip_sync.py`: `LipSyncAPI` クラスを提供し、タスク作成・取得・一覧を非同期で実行。`tenacity` によるリトライ戦略を組み込み。
- `_requests.py`: タスク作成・一覧 API のクエリを Pydantic モデル化。
- `_responses.py`: `TaskResponse` や `TaskData` モデルを定義し、API 応答を型安全に扱う。
- `_exceptions.py`: レート制限・タイムアウト・サーバエラーなどを分類する独自例外とユーティリティ。
- `_tests/`: モック HTTP クライアントを用いてエラーパスと正常系を検証。

## 機能ハイライト
- `/v1/lip-sync/tasks` エンドポイントの作成・取得・一覧に対応。
- バリデーションエラー時は `LipSyncValidationError`、レート制限時は `LipSyncRateLimitError` を送出。
- 音声・動画素材の同期を行うマルチメディアパイプラインに組み込みやすい構成。

音声台詞とキャラクター映像を自動で同期させたいユースケースでご利用ください。
