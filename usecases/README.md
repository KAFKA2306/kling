# ユースケース実装

`usecases` ディレクトリには SDK を利用した高レベルな業務ユースケースの実装例が含まれます。複数の API 呼び出しやバリデーションをまとめたオーケストレーション層として機能します。

## ファイル構成
- `text_to_video.py`: `GenerateTextToVideoUseCase` クラスを提供し、`KlingClient` を受け取ってテキスト→動画生成をワンメソッドで呼び出せるようにする簡易ユースケース。
- `__init__.py`: パッケージとしてユースケースを再エクスポート。

## 利用方法
アプリケーション側では `GenerateTextToVideoUseCase` を DI などで注入し、プロンプト検証や追加オプションの組み立てを行った上で `execute` を呼び出します。失敗時の例外はそのまま伝播するため、呼び出し元でハンドリングしてください。
