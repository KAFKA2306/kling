# クイックスタート

KlingAI API プラットフォームへようこそ。本ガイドでは、リソースパックの購入、API キー管理、テスト方法、利用状況やビジネスに関する問い合わせなど、API 連携に必要な主要機能を総覧します。ご利用中に不明点があればお気軽にお問い合わせください。

## ステップ 1：KlingAI API プラットフォームへアクセス

- プラットフォーム：https://klingai.com/global/dev
- 動画生成モデル：https://klingai.com/global/dev/model/video
- 画像生成モデル：https://klingai.com/global/dev/model/image
- インテリジェントシナリオ（バーチャル試着など）：https://klingai.com/global/dev/model/tryon

## ステップ 2：リソースパックの購入

動画生成・画像生成・バーチャル試着の 3 種類の API リソースパックが利用可能です。用途に合わせてプランを選択してください。共同検証やテスト向けの「トライアルリソースパック」も用意しています。詳細は購入ページをご覧ください。

- 動画生成 API 購入ページ：https://klingai.com/global/dev/model/video
- 画像生成 API 購入ページ：https://klingai.com/global/dev/model/image
- バーチャル試着 API 購入ページ：https://klingai.com/global/dev/model/tryon

リソースパックを選択して注文します。基本パックの同時実行数（同時に生成できる動画や画像の数）は、追加購入しても自動的には増えません。大量利用や高い同時実行ニーズがある場合は「カスタマイズリソースパック」からご相談ください。専任チームが最適な構成を提案します。

決済ページではクレジットカードでお支払いが可能です。支払い完了後は購入ページ右上の「コンソール」から、利用状況照会、注文管理、リソースパック管理、キー管理にアクセスできます。

## ステップ 3：API キーの取得

Kling AI API プラットフォームのアカウントでは、Access Key を生成できます。API 呼び出し時は「Access Key ID」と「Access Key Secret」で認証を行います。これらは課金トリガーとなる唯一の資格情報のため、厳重に管理してください。プラットフォームではキーの有効化／無効化／削除が可能です。

- Access Key には Access Key ID と Access Key Secret が含まれます。  
  - Access Key ID：ユーザー識別用 ID  
  - Access Key Secret：ユーザー検証用シークレット。漏洩しないよう十分にご注意ください。

デフォルトで 1 組のキーが発行されます。「Create New Key」をクリックすると 2 組目のキーを生成できます。キーが漏洩・紛失した場合は新しいキーを作成してください。1 アカウントで保持できるキーは最大 2 組で、同一アカウントのリソースパックや同時実行制限を共有します。

## ステップ 4：API サービスの利用

ドキュメントセンターで詳細な API 呼び出し手順を確認し、必要なエンドポイントを利用してください。

- 「Kling AI」API 概要：「Kling AI」API
- 「Kling AI」API ドキュメント：「Kling AI」API Documentation

インターフェース／モデルごとに課金方法が異なります。購入ページ下部の【Quick Note】に記載された注意事項を参照してください。

## ステップ 5：消費状況の確認

「コンソール → データセンター → 消費照会」でリソースパックの利用状況を確認できます。

## ステップ 6：リソースパックと注文管理

- **リソースパック管理**：「コンソール → データセンター → リソースパック管理」で各パックの詳細を確認できます。
- **注文管理**：「コンソール → データセンター → 注文管理」で注文履歴を確認できます。
