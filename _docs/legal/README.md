# 法的ドキュメント

`_docs/legal` ディレクトリには Kling AI サービスを利用する際に確認すべき法的文書がまとまっています。各ファイルは API 利用時の権利義務やデータ取り扱いに関する規定を示しています。

## 収録文書
- `terms.md`: API の利用規約。利用者の責務や禁止事項、サービス提供範囲を定義。
- `privacy.md`: プライバシーポリシー。収集されるデータとその保護方針を解説。
- `api_agreement.md`: 企業間で締結する API 契約書のテンプレート。

## 利用のポイント
プロダクション導入前に必ず各文書を関係者と共有し、遵守事項を確認してください。社内コンプライアンス部門によるレビューや、カスタマイズ契約を締結する場合のベース資料として活用できます。
