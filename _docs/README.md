# ドキュメントディレクトリ概要

`_docs` ディレクトリには Kling AI Python SDK の利用を支援するための利用ガイドと参照資料がまとまっています。導入から法的事項までを日本語で確認できます。

## 主なファイル
- `quick_start.md` / `getting_started.md`: SDK を素早く使い始めるためのチュートリアル。
- `feature_list.md` / `advantages.md`: 提供される機能と採用メリットの整理。
- `billing_method.md` / `prepaid_resource_packs.md`: 課金方式やプリペイドパックの説明。
- `calability_map.md`: スケール性とアーキテクチャに関するまとめ。

## サブディレクトリ
- `legal/`: API 利用規約やプライバシーポリシーなど、法的文書を格納。

## 利用方法
SDK の導入・運用フローを確認したい場合は、まず `quick_start.md` を参照し、その後必要に応じて詳細ドキュメントを読み進めてください。集約された資料を活用することで、開発チーム全体で一貫した運用手順を共有できます。
