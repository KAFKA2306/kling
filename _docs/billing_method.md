# 課金方法

- 現時点で Kling ではプリペイド型のリソースパックのみを提供しています。
- リソースパックは提供機能に応じて「動画生成」「画像生成」「バーチャル試着」の 3 種類に分類されます。

## プリペイドリソースパック

### 動画生成リソースパック

- 説明：動画生成で利用可能な汎用クレジットパックです。
- 利用範囲：text-to-video、image-to-video、video-extension、lip-sync などの動画生成 API を利用できます。
- クレジット単価：標準価格は 1 クレジットあたり 0.14 米ドルです。
- 有効期限：各パッケージにはアクティベーション日と失効日があり、期限切れの未使用クレジットは無効になります。
- 同時実行：同時に生成できる動画本数を指します。
- ティア構成：同じ有効期間では、クレジット数と同時実行数が多いほど割引率が高くなります。以下は参考用の 3 ティアです（業務向けカスタマイズや大量購入は公式チャネルまでお問い合わせください）。
