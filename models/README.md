# Pydantic モデル

`models` ディレクトリには、Kling AI 各 API のリクエスト/レスポンスを型安全に扱うための Pydantic モデルが集約されています。SDK 全体で統一したバリデーションやフィールド名（`alias` 設定）を共有することで、実行時エラーを最小化します。

## ファイル構成
- `text_to_video.py`: テキスト→動画タスクのリクエスト・レスポンス・タスクリストモデル。タイムスタンプをミリ秒 UNIX から `datetime` へ変換するバリデータを内蔵。
- `image_to_video.py`: 画像→動画用モデル。マスクやカメラ制御、CFG スケールなど豊富なパラメータをサポート。
- `multi_image_to_video.py`: 複数画像からの動画生成タスクモデル。シーケンス指定や遷移制御に対応。
- `video_extension.py`: 動画延長タスクのモデル。延長範囲や効果設定を表現。
- `lip_sync.py`: リップシンクタスクのステータス列挙や進捗情報、結果 URL を含むレスポンスモデル。

## 利用のポイント
- すべてのモデルが厳格な型定義を持つため、`model_validate` / `model_dump` を通じて API と連携するとフィールド名のずれや型変換ミスを防げます。
- 一部モデルは `field_validator` を用いて URL 形式やタイムスタンプ変換を自動化しています。
- `KlingConfig` で定義される列挙値（アスペクト比・動画モードなど）を参照することで、SDK 全体の設定が同期されます。

API クライアントで新たなエンドポイントを実装する際は、本ディレクトリに対応するモデルを追加してからクライアントコードを作成してください。
